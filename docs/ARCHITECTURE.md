# Architecture

## Overview

```
Browser (React + Vite + Three.js)                 Python backend (FastAPI, local only)
─────────────────────────────────                 ─────────────────────────────────────
Camera (getUserMedia, 640x480, 30 fps)            /ws/live   LiveSession (backend/asl/seq/live_session.py)
  ── capture time (8 bytes) + JPEG ─WebSocket──►    1. decode JPEG, mirror
   ▲  one frame in flight at a time                 2. MediaPipe Hands → 21 landmarks   [supporting tool]
   │                                                 3. 68 features per frame            (backend/asl/seq/features.py)
   │                                                 4. OUR TCN + CTC model, streaming   (backend/asl/seq/inference.py)
   └──────────── JSON result ◄───────────────────    5. live words: word decoder        (backend/asl/seq/word_decoder.py)

Words under the video, state pill  ◄── {"type":"frame", hand, confirmed, current, process_ms}
3D hand (procedural Three.js rig)  ◄── the same 21 hand points (follows your hand), or a resting open hand
Finish (F) ─► whole-sentence re-decode ─► {"type":"text", finished_text} → caption bar, spoken once if enabled

Microphone → AudioWorklet (16 kHz PCM) ─WebSocket─► /ws/speech → Vosk (offline)   [optional]
```

Everything runs on `127.0.0.1`. Nothing is sent to an external service.

## Where the "own trained model" requirement is met

The letters are decided only by our TCN + CTC model (`backend/asl/seq/model.py`), trained by us
in Google Colab and loaded from `backend/models/final_model_i/`. MediaPipe only supplies hand
landmarks; the word decoder chooses between words using the model's own letter probabilities.
Vosk and the browser's speech synthesis are separate optional features and never affect recognition.

## Python package `backend/asl/`

| Module | Responsibility |
|---|---|
| `features.py` | Wrist-centred finger shape of one hand (the first 63 of the 68 sequence features). |
| `tracker.py` | Thin MediaPipe wrapper. |
| `speech.py` | Optional Vosk wrapper with clear "not installed" status. |
| `seq/` | The sequence model: features, TCN + CTC model, training, streaming inference, live session, word decoder. See [SEQUENCE_MODEL.md](SEQUENCE_MODEL.md). |

## Live reading details

* **One frame in flight.** The browser sends the next frame only after the reply to the
  previous one arrives, so there is never a queue of old frames. Each frame carries its
  capture time, so the model sees the real signing speed.
* **States** shown to the user: `Camera off`, `Press Start to read your signing`,
  `No hand detected`, `Reading your signing…`.
* **Words:** confirmed words, then the current guess (which can still change), shown alike.
* **Finish sentence** reads the whole sentence once more, stores it and keeps reading.
* The model loads the first time reading starts and is compiled before the first frame.
* **Replay check without a webcam:** `set ASL_LIVE_REPLAY=<a saved take .npz>` before starting the
  server, then open `http://127.0.0.1:8000/?replay=1`.

## 3D hand

`frontend/src/lib/handRig.js` builds an original hand from spheres, tapered
cylinders and a convex palm (no third-party model, so no licence issue).
On the camera screen it follows the live hand points (sized by the palm, lightly smoothed,
drawn in the browser, so it does not slow the model) and glides back to a resting open hand.
Reference poses for speech mode and the ASL Alphabet screen come from
`frontend/public/reference_poses.json`, generated by `scripts/app/build_reference_poses.py`
as the **medoid real sample** of each letter. Each pose carries a verification status; see
[TRAINING_AND_EVALUATION.md](TRAINING_AND_EVALUATION.md#reference-poses).
J and Z add a whole-hand motion path from the written description. Repeated letters in
speech mode show a short sideways slide.

## Front end

| File | Purpose |
|---|---|
| `src/App.jsx` | Layout, side strip, keys, state, glue (camera ↔ backend ↔ captions ↔ speech ↔ hand). |
| `src/lib/useRecognition.js` | WebSocket + capture loop (one frame in flight). |

| `src/lib/useSpeechSynthesis.js` | English voices, rate, enable toggle, speak/stop. |

| `src/components/*` | Panels and screens. |
| `src/components/AlphabetScreen.jsx` | ASL Alphabet screen (side bar): step through all reference poses for verification. |
